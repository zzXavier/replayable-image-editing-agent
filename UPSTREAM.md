ComfyUI: https://github.com/Comfy-Org/ComfyUI/tree/55add502206ed5511a04215db4ab8f1cfa3d99ae (GPL-3.0). The server is installed separately. The HTTP API and standard CheckpointLoaderSimple, CLIPTextEncode, InpaintModelConditioning, KSampler, VAEDecode and SaveImage nodes handle native inpainting. No server code or bundled checkpoint is redistributed. Select a model with native ComfyUI inpainting support under its own weight terms and record its SHA-256 alongside results. ABO sources and attribution in data.md.

P01 handoff: four 384 px product packshots, masks, requests and per-PNG hashes from the product-background-editing src/prepare_examples.py export are checked into examples/products. This independent repo loads them offline via src/data.py.

The published reproduction uses the SD1.5 Diffusers base at https://huggingface.co/stable-diffusion-v1-5/stable-diffusion-v1-5/tree/451f4fe16113bff5a5d2269ed5ad43b0592e9a14 via masked latent sampling. This four-channel model uses the public P01 input and mask bundle. A nine-channel inpainting checkpoint can be supplied as an alternate experiment.
